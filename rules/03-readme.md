# README

Debe estar enfocado en quien va a usar la app, no en quien la desarrolla. Tiene que incluir únicamente:

1. **Qué es la aplicación y para qué sirve** — propósito y funcionalidad principal, en lenguaje simple.
2. **Tecnologías usadas** — lista simple (lenguaje, framework de escritorio, backend, base de datos, etc.).
3. **Cómo correrla en el dispositivo** — requisitos y comandos para instalarla/arrancarla.

## Lo que NO debe incluir

- Arquitectura interna, diagramas de carpetas, decisiones de diseño técnico.
- Explicaciones largas o relleno innecesario.

## Tono

Directo, breve, claro. Alguien que lo lea debe entender en segundos qué hace la app y cómo usarla.
